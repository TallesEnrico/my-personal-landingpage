# Talles Enrico — Portfólio

Front estático (Vite + React + Bun). Sem backend.

## Stack

- Vite
- React + TypeScript
- Tailwind CSS
- Framer Motion
- React Three Fiber
- Bun

## Comandos

```bash
make install
make dev
make build
make deploy
```

Publica em https://www.tallesenrico.com.br via Cloudflare Pages.

## Conteúdo

Edite `src/data/` para atualizar textos, projetos e experiência.
